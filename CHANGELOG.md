# Changelog

## v1.2
- Безопасность: адреса своих списков больше не попадают в заголовок hosts (его может прочитать любое приложение).
- Безопасность: проверка домена больше не пингует его.
- Загрузка: лимит 64 МБ на файл; если curl не справился, пробуются curl из Termux и wget.
- hosts не обнуляется, если в /data не хватает места.
- Предупреждение, когда доменов больше миллиона (DNS начинает тормозить).
- WebUI: домен в проверке передаётся в кавычках.
- Сборка: actions/checkout закреплён по хешу коммита.

## v1.1
- Первый публичный релиз.
- Авторы и лицензии списков указаны в WebUI, `nullads help` и README.
- При скачивании списков отправляется честный User-Agent `NullAds/<версия>`.
- Менеджер root сам находит обновления модуля (updateJson).
- Кнопка «Поддержать» в WebUI.
